# go-innovation-rnd

기술경영·R&D·IP 사업화를 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 기술 로드맵, R&D 포트폴리오와 스테이지게이트, 개방형 혁신, 특허·영업비밀 같은 IP 전략과 직무발명, 기술이전·사업화, 그리고 정부 R&D 과제 수행(공모·협약·연구개발비 정산·성과 관리)을 한국의 제도(국가연구개발혁신법, 발명진흥법, 특허법, 기술이전법, 기업부설연구소 인정, 연구·인력개발비 세액공제의 구조) 위에서 배우고, ISO 56000 계열·OECD Frascati Manual·미국 Bayh-Dole Act·독일과 일본의 직무발명 제도 같은 국제 기준과 비교합니다.

첫 정부과제를 준비하는 분도, 연구소·특허·정부과제를 오래 맡아 왔지만 체계와 제도 근거를 정리하고 싶은 관리자도 대상입니다. 마지막에는 내 상황에 쓸 **정부 R&D 과제 제안서 골격**과 **R&D 포트폴리오 표**를 만듭니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료, 이미지를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-innovation-rnd
```

**Claude Code**

```bash
cd ~/Desktop/go-innovation-rnd
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-innovation-rnd` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, R&D·특허·정부과제를 어떻게 겪어 봤는지(지금 맡은 일 포함) 짧게 묻고, 영역마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. 이 분야가 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 내 상황을 비튼 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다. 경력, 과제 수행 건수, 특허 건수만으로는 넘어가지 않습니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML(기술 로드맵, 포트폴리오 지도, 협약·정산 흐름도 등)을 만들어 가며 익힙니다. 포트폴리오 표·제안서 골격 같은 문서는 내가 직접 씁니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내가 쓴 문서. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 법령과 기준에 대해

- 튜터는 법령·고시의 조문 번호, 금액, 비율, 기한을 말하기 전에 국가법령정보센터 같은 공식 출처에서 다시 확인하고, 확인하지 못하면 그렇다고 말합니다. 정부 R&D 고시와 세액공제는 자주 바뀌므로 실제 업무에서는 원문과 전문기관 공고를 직접 확인하세요.
- 튜터는 법률·세무 자문을 하지 않습니다. 내 직무발명 보상, 특허 귀속 분쟁, 제재 처분, 세액공제 여부의 결론은 변리사·변호사·세무사·전문기관과 확인하세요.
- **아직 출원하지 않은 발명의 내용은 대화에 넣지 마세요.** 발명이 공개되면 신규성을 잃을 수 있고, 대화 내용과 웹 조사 질문은 외부 서비스로 전달됩니다. 실제 협약서·계약서, 회사·사람 이름, 금액, 개인정보도 붙여 넣지 말고 지운 요지만 말해 주세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 문서를 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 민감한 정보는 대화에 넣지 마세요.
